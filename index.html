☁ Cloud Sync (GitHub Gist)

One-time setup per device. This saves your progress to a private GitHub Gist so both your iPad and Mac stay in sync automatically — no files, no copy/paste, no exports.

  1. Go to github.com/settings/tokens → Generate new token (classic) → check only the gist scope → Generate.
  2. Paste that token below. Leave Gist ID blank on your FIRST device — it will be created for you.
  3. On your SECOND device, paste the SAME token and the Gist ID shown after step 2.
